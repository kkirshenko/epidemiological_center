# Руководство пользователя

## 1. Вход в систему
1. Откройте `/login`.
2. Введите логин и пароль.
3. После успешного входа используйте меню для перехода к разделам.

## 2. Работа с организациями
- Раздел `/organizations` — список, поиск и сортировка.
- Карточка организации `/organizations/{id}`.
- Создание/редактирование через формы `/organizations/new` и `/organizations/{id}/edit`.

## 3. Работа с проверками
- Раздел `/inspections` — список, фильтрация, сортировка.
- Карточка проверки `/inspections/{id}`.
- Создание/редактирование через формы `/inspections/new` и `/inspections/{id}/edit`.

## 4. Работа с нарушениями
- Раздел `/violations` — реестр нарушений.
- Просмотр и изменение карточки нарушения в соответствующих формах.

## 5. Права доступа
- ROLE_ADMIN: полный доступ.
- ROLE_INSPECTOR: операции с проверками и организациями.
- ROLE_LABORANT: доступ к нарушениям и чтению данных.

# Руководство пользователя

Данное руководство описывает порядок работы в веб-интерфейсе системы санитарно-эпидемиологического центра `epidemiological_center`. Материал ориентирован на конечных пользователей: **Инспекторов (Проверяющих)** и **Лаборантов**.

---

## 1. Вход в систему

1. Откройте браузер и перейдите по адресу: `http://<адрес_сервера>:8080`
2. На странице авторизации введите:
   - **Логин** (username или email)
   - **Пароль**
3. Нажмите **Войти**.
4. При первом входе система может предложить сменить временный пароль. Следуйте инструкциям на экране.

> Если учётная запись заблокирована или права не назначены, обратитесь к администратору системы.

---

## 2. Общий интерфейс и навигация

После успешного входа вы попадаете на **Главную панель (Dashboard)**. Интерфейс состоит из следующих зон:

| Зона | Описание |
|------|----------|
| **Боковое меню** | Основные разделы системы. Состав зависит от вашей роли. |
| **Верхняя панель** | Глобальный поиск, уведомления, меню профиля, кнопка выхода. |
| **Рабочая область** | Таблицы, формы, графики и детали выбранных объектов. |
| **Строка статуса** | Отображает текущий фильтр, количество записей и состояние загрузки. |

**Общие принципы навигации:**
- Клик по строке таблицы открывает карточку объекта.
- Кнопки действий расположены в футере.
- Статусы объектов выделены метками:  Активно, В работе, Закрыто/Нарушение.
- Все изменения сохраняются автоматически или по кнопке **Сохранить**.

## 3. Роль: Инспектор (Проверяющий)

Инспектор отвечает за планирование проверок, фиксацию нарушений и выдачу предписаний.

###  Типовой рабочий процесс

1. **Создание проверки**
   - Перейдите в раздел `Проверки` → нажмите **Создать проверку**.
   - Заполните форму проверки:
     - **Организация** — выберите объект проверки из выпадающего списка
     - **Тип проверки** — выберите тип (плановая/внеплановая/повторная)
     - **Проверяющий** — назначьте ответственного инспектора
     - **Плановая дата** — укажите дату проведения (дд.мм.гггг)
     - **Статус** — по умолчанию «Запланирована»
     - **Результат** — по умолчанию «Ожидается»

2. **Дополнительные сведения**
   - При необходимости заполните поля:
     - **Краткое заключение** — предварительные выводы или цель проверки
     - **Рекомендации** — особые указания для проверяющего
     - **Номер акта** — присвойте номер (можно заполнить после проверки)
   - Нажмите **Сохранить** для создания записи.

3. **Проведение проверки**
   - В день проверки откройте карточку из списка.
   - Зафиксируйте результаты:
     - Измените **Статус** на «В процессе» или «Завершена»
     - Обновите **Результат** (соответствует/не соответствует/частично)
     - Внесите фактические данные в **Краткое заключение**
     - Укажите **Номер акта** проверки

4. **Фиксация нарушений**
   - Если выявлены нарушения, в карточке проверки нажмите **Добавить нарушение**.
   - Для каждого нарушения укажите:
     - Статью нормативного акта
     - Описание отклонения
     - Степень риска (низкая/средняя/высокая)
     - Сроки устранения

5. **Формирование итогов**
   - После завершения всех проверочных мероприятий:
     - Установите **Статус**: «Завершена»
     - Внесите итоговое **Результат** проверки
     - При необходимости сформируйте акт в формате PDF
     - Нажмите **Сохранить** для фиксации окончательных данных

Поля, отмеченные звёздочкой (*), обязательны для заполнения.

## 4. Роль: Лаборант

Лаборант отвечает за документирование и контроль устранения нарушений, выявленных в ходе проверок или лабораторного контроля.

### Типовой рабочий процесс: Оформление нарушений

1. **Привязка к проверке**
   - В поле **Проверка** выберите из выпадающего списка мероприятие, к которому относится нарушение (например, `Федеральная городская поликлиника №1 — 30.05.2026`).
   - Это поле обязательно для заполнения (*).

2. **Детализация нарушения**
   - В поле **Описание** введите подробный текст выявленного отклонения от норм.
   - Это поле обязательно для заполнения (*).

3. **Оценка серьёзности**
   - В поле **Серьёзность** выберите категорию нарушения (например, `Незначительное`, `Среднее` или `Критическое`).
   - Это поле обязательно для заполнения (*) и влияет на приоритет исправления.

4. **Мониторинг статуса**
   - В поле **Статус устранения** укажите текущее состояние проблемы (по умолчанию установлено `Не устранено`).
   - По мере работы над нарушением статус можно изменять.

5. **Сохранение записи**
   - После заполнения всех обязательных полей нажмите кнопку **Сохранить** для фиксации данных в системе.
   - Для возврата к списку нарушений используйте кнопку **Назад к списку** в правом верхнем углу.
